# Module 2: Preprocessing, Models, and Diagnostics

This foundational module teaches concepts reused across the applied projects.
It is distinct from [Project 1: Linear Regression](../Project_01_Linear_Regression/)
and [Project 2: Classification](../Project_02_Classification/).

## Existing materials

- [Module 1/2 study guide](Module_1_2_Study_Guide.docx): data interpretation,
  preprocessing decisions, regression training, residuals, and
  train/validation/test roles.
- [Model-training handout](linear-rgression-models-handout.docx): Normal
  Equation versus Gradient Descent, loss, parameters, and held-out evaluation.
- [Module 1 materials](../Module_01_EDA/): EDA, outlier handling,
  transformation decisions, and categorical-feature preparation.
- [Project 1 lab](../Project_01_Linear_Regression/linear-regression/):
  runnable examples of standardization, model fitting, convergence, and
  train/test metrics.

## Coverage and next steps

The existing materials introduce preprocessing, regression modeling, and
basic evaluation. They do not yet constitute a complete preprocessing pipeline
or comprehensive regression-assumption diagnostics.

Project 2 will extend these foundations to classification. Its dataset and
image-preprocessing scope are still being selected; segmentation is a possible
extension, not yet a required deliverable.
