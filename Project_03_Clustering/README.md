# Project 3: Clustering

Clustering is **unsupervised learning**: discover useful groups from input
measurements without training on known class labels. A cluster is a proposed
pattern, not a confirmed species, customer identity, or causal explanation.

Start with [K-means: From Customers to Centroids](k-means/README.md).
The folder contains a visual lesson, worked arithmetic, student practice,
guided notebook, runnable script, homework, and student rubric.

This is the clustering project identified in the syllabus, not Module 3
(FastAPI and Docker). K-means is a first method, not the entire clustering
subject. Hierarchical and density-based methods are future comparisons,
especially for non-spherical groups or noise.
